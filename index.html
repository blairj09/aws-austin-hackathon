from chatlas import ChatBedrock

analyst = ChatBedrock(
    model="us.anthropic.claude-sonnet-5-5",
    api="converse", system_prompt=ANALYST,
)
analyst.register_tool(failure_rate_by)
analyst.register_tool(show_signal)  # drives the chart

# another agent, exposed as a tool
analyst.register_tool(consult_planner)

Maintenance copilot. An analyst agent answers with your Python functions, updates the dashboard, and hands off to a planner agent for next steps.

library(commons)

agent <- commons(
  client = ellmer::chat_aws_bedrock(
    model = "us.anthropic.claude-sonnet-5-5"
  ),
  data_sources = list(
    maintenance = data_source(machines = machines)
  ),
  semantic_layer = semantic_layer("measures"),
  context_layer = context_layer("context.md")
)
commons_app(agent)

Track 2 machine health. The agent runs your trusted R code first, then marks every answer with where it came from: trusted code, cited sources, or new SQL. commons is experimental.

Whatever track you’re on, the shape is the same. It starts with data: explore it in Positron. Turn the calculations you trust into plain functions you can test. Give each persona its own chat with its own tools, and log the handoffs. Put a Shiny front end on it, or use commons to get provenance built in. If you want to deploy, wrap the Python agent in the AgentCore handler from the starter kit, and your Shiny app calls it as a managed endpoint.
